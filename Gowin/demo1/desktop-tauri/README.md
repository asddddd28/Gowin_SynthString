# Tang Synth Studio · Tauri 桌面版

面向 Tang Mega 60K 的音色编辑与演奏上位机。0.4.0 在 Tauri 2 + React/TypeScript 界面和原生 Rust 后台上加入旋钮、演奏控制与原生 MIDI 输入。后台直接编入主 EXE；构建和运行均不需要 Python。原 Tk 程序、0.2.0 / 0.3.0 发布目录和已冻结 FPGA 发布文件继续保留。

## 使用

双击 `release-performance/TangSynthStudio/TangSynthStudio.exe`（在便携包里直接双击同目录 EXE）。请保留 `assets` 音色资源与 `licenses`。需要 Windows 10/11 与 WebView2 Runtime；无需另装 Python、Node 或 Rust。旧版的 `tang-engine.exe` 不参与运行。

1. 在“音色浏览器”搜索音色；耳机图标播放随附的 C3/C4/C5 电脑参考音频，底部可以停止。点击“载入音色”保存到当前音键。
2. “声音设计”可以编辑两个振荡器、混合/FM/AM/环形调制、音量/调制 ADSR、音高、力度、电脑键盘映射和双帧位置。调制设置在包络面板的第三个分页。保存与同步是两个明确动作。
3. 插入 DEBUG USB，刷新串口、连接，等待 FPGA 状态包，再点击“同步此键”。收到参数校验确认后才允许起音。底部 32 音键支持鼠标按住与电脑键盘；切页、失焦会释放音符，Esc 紧急停止。界面停止发送心跳超过 1.5 秒时，后台也会释放音符。
4. “波表工坊”可以载入原生 WT、Surge WAV、TSWT、资源目录或既有单周期文本格式，预览前/后帧与混合曲线，上传单帧或双帧。也保留谐波钢琴表与 PCM 包入口。
5. “Surge 桥接”连接本机 OSC、导入/导出快照并转换场景 A/B 的音量 ADSR；保存到当前键后再同步。源端口默认 53280，接收端口 53281。
6. “设备与输出”显示真实硬件状态、调整主音量与输出增益，并导入/导出 JSON 配置。覆盖 32 键的模板操作有单独确认。

Tauri 使用 `%LOCALAPPDATA%/TangSynth32/settings-tauri.json`。首次运行没有新配置时，读取旧 `settings-pcm.json`；之后写入新文件。请避免同时让两个应用占用同一串口。基础音色的波表绑定保存在 `tauri_bindings`，用于下次同步时重传所需资源。

## 旋钮与参数编辑

声音设计页可切换旋钮／滑杆，并记住选择。旋钮上下拖动，按住 Shift 精调；聚焦旋钮后可用滚轮、方向键、Page Up / Down 调整，Home / End 到达端点。双击或按 Enter 复位。包络时间使用对数拖动，让短时间区域更容易调节；数值框仍直接输入毫秒。数值框支持暂时清空，Enter 或失焦时校验范围。

振荡器电平、ADSR 复位到已保存值；其余参数复位到该控件打开时的值。撤销／重做针对当前键的本次编辑，保存或换键后清空历史。Ctrl+S 保存，Ctrl+Shift+S 保存并同步，Ctrl+Z / Ctrl+Shift+Z 撤销／重做；在文本框中仍使用系统的文本撤销。

## 电脑键盘、触控与 MIDI

- 演奏区支持多键键盘和多个触点。同一音键被多个输入按住时，最后一个输入释放才关音。开启“触点力度”后，按键触点越靠下力度越大。
- “锁定编辑键”允许演奏其他键而不切换编辑对象；右键仍可选择编辑对象。“按住演奏当前键”方便边试听边调整。小窗口可“收起控制”，保留全部 32 个演奏垫和键盘输入。
- 延音可点击踏板锁定，也可在空白处按住 Space；若 Space 已映射音键则保留原映射。输入框、选择框、旋钮和普通按钮有自己的键盘操作，避免编辑时误发音。松开踏板只释放已松手的音符。
- 临时移调支持上下两个八度，点击中间数值归零。移调或 MIDI 通道变化会先释放旧音符。统一力度用于电脑键盘／鼠标；触点力度和 MIDI 原始力度优先。移调、统一力度、延音均为本次会话状态，不覆盖每键设置。
- MIDI 输入由 Rust `midir` 接收，选择设备后点击连接；支持通道筛选、Note On / Off、零力度 Note On、CC64 延音、CC7 主音量、CC120 / CC123 释放音符。输入音符匹配已保存的音键音高；重复音高使用第一个音键，未分配音符只显示提示。收到的音高再叠加临时移调。
- 窗口失焦、隐藏、切离声音设计页、弹出对话框或开始绑定快捷键时，暂停演奏并释放全部音符。MIDI 断开或输入队列过载也会释放音符；MIDI 事件不能代替界面心跳。Esc 是紧急停止。

## 实时控制的生效范围

| 控制 | 生效方式 | 保存方式 |
| --- | --- | --- |
| 演奏区主音量、MIDI CC7 | 立即发送全局音量命令，包含正在发声的声部；最多 20 次／秒，合并中间值 | 本次会话；在“设备与输出”应用输出设置才能持久保存 |
| 开启实时参数同步后的振荡器、混合／调制、ADSR、已驻留双帧位置 | 连续拖动时前端每 100 ms 取最新参数，后台上传间隔至少 150 ms；串行等待协议确认，确认后下一次起音生效 | 点击“保存”才写入配置文件；保存已确认的预览不打断持音 |
| 每键音高、力度、快捷键、名称 | 保存后使用，修改映射时释放旧音符 | 保存到电脑，音色参数需要同步 |
| 新波表、PCM 资源 | 显式上传并确认；不随旋钮自动换资源 | 使用原资源上传流程 |

实时参数上传期间保留原持音，正在更新的键暂时禁止新起音，其他已确认的键仍可演奏。不会通过反复重触发音符伪装持音参数更新。确认超时会关闭自动同步，并把失败键标为待同步。关闭实时开关只停止后续上传，硬件保留最后确认的预览；放弃未保存修改并离开时，会排队恢复已保存的参数。恢复仍需要硬件确认。

## 能力边界

- 对接现有 `demo1_pair_31002.fs` / `demo1_pair_31004.fs` 的协议，没有新增或烧录位流。
- 板上只有一对共享波表。不同波表音色需分别同步；换表后其他自定义波表键重新标记为待同步，不能把 GUI 的多个音色理解为硬件已同时驻留多个资源。
- 基础音色的电脑试听是浮点参考音频，不是 Surge 渲染或 FPGA 录音。振荡器图表示形状；ADSR 图是线性阶段预览，持续段时长是展示值。
- Surge 自动转换仍限于音量 ADSR，尚未扩展到完整滤波、效果与调制矩阵。此次只移植界面和控制流程，不改变 FPGA 合成精度或原移植进度。
- 外接 MIDI 通过电脑接收再转发到现有串口协议；尚未实现独立板端 USB MIDI、Pitch Bend、CC1 调制轮和持音过程中的振荡器／滤波器连续更新。
- 当前默认中文界面。界面英语小标题作为辅助标识，尚未加入完整英文语言切换。

## 构建与验证

```powershell
cd D:/Projects/ai/Gowin/demo1/desktop-tauri
$env:Path = "$env:USERPROFILE/.cargo/bin;" + $env:Path
npm.cmd ci
npm.cmd run prepare:assets
npm.cmd run tauri dev

# 正式便携目录（内嵌前端和 Rust 后台的主 EXE + 资源 + 许可证）
npm.cmd run desktop:build

# Rust 协议对照、状态与资源校验 / Edge 无头界面
npm.cmd run test:backend
npm.cmd test

# 实际 Tauri WebView2 → 原生 Rust 后台
npm.cmd run tauri -- build --debug --no-bundle
node scripts/native-smoke.mjs
node scripts/native-smoke.mjs --release
```

构建使用 Node 24、Rust MSVC 和 Visual C++ Build Tools。`npm run build` 仅构建前端；单独打开浏览器会明确提示必须用 Tauri 启动。无头 UI 测试调用真实 Rust 控制器；串口记录器仅在 `test-harness` 特性下编译，正式构建不启用该特性。协议对照 JSON 由历史 Python 实现一次性生成并保存，日常测试不运行 Python。

项目分层：`src/` 是 React 界面；`main.rs` 管理窗口和 Tauri command；`runtime.rs` 使用有界请求队列调度 `engine.rs`，每轮检查界面心跳；`performance.rs` / `performance_control.rs` 管理演奏归属、踏板、移调和实时确认队列；`midi.rs` 的回调只向有界队列发送解析后的事件，不直接写串口；`transport.rs` 的独立串口线程负责 115200/8N1、心跳和读写超时；`protocol.rs` 负责报文、CRC、token/generation 及分块确认状态机；`model.rs` 校验配置并编码高精度包络；`resources.rs` 校验音色库、TSWT/WT/WAV/PCM；`surge.rs` 仅在本机回环地址读取 OSC。配置写入临时文件并刷盘后替换，成功后才更新内存状态。

上传波表时先取消对旧共享波表的驻留信任，避免提交 ACK 丢失后使用错误资源。传输过程中按 Esc 会中止传输并断开设备，需要重新连接同步。窗口关闭时停止试听、OSC 和串口线程，并尽力发送各上传中止命令及全音符停止。

素材与方案来源见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。本版验证日志和实际窗口截图位于工程 `reports/performance_*` 与 `reports/performance-*`；历史 Tauri 0.2.0 / Rust 0.3.0 报告另行保留。自动化覆盖真实 Rust 控制器与模拟协议确认、MIDI 事件，未连接实体 MIDI 键盘或 UART，实际演奏延迟、踏板和声音仍需接板验收。
