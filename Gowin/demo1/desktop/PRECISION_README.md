# 高精度包络与输出增益版

程序：`release_precision/TangSynth32/TangSynth32.exe`。保留整个文件夹，包括 `_internal` 和 `samples`。

本版本需要更新 FPGA：选择与当前串口可正常通信的底板版本一致的 `output/demo1_precision_31004.fs` 或 `output/demo1_precision_31002.fs`。新程序会检查固件能力，旧固件不会被显示为音色参数上传成功。此处没有自动烧录或改写开发板 Flash。

## 试听

1. 关闭旧程序，烧录对应 precision 固件，然后打开新程序并连接 DEBUG UART。
2. 等待逐键音色确认。默认输出增益为 ×1；若单音偏小，选 ×4 或 ×8，点击“仅设置总音量”。观察底部削波计数；持续增长时降低音量或增益。
3. 右键音键，打开“音色参数…”，把 A 设置为 5000 ms，保存并上传。持续按住该键，攻击段应接近五秒。
4. PCM 仍需先导入 `samples/Piano_C4_PCM.json`，随后可导入 `PCM_Piano_32Keys.json`。采样数据在 FPGA RAM，复位或断电后需重传。

攻击、衰减和调制包络采用分数步长。释放保持峰值参考的线性速度，所以提前松键或从较低持续电平释放时，实际释放会更短。零时间立即完成，偷音行为保持兼容。

输出增益依次为 ×1/×2/×4/×8/×16，界面显示约 0/+6/+12/+18/+24 dB。增益有平滑过渡；过载采用硬饱和并计数。PT8211 的十六位转换采用正负对称舍入。当前没有加入软限幅器、抖动、波表插值或抗混叠。

用户配置继续使用 `%LOCALAPPDATA%/TangSynth32/settings-pcm.json`；旧配置的时间参数与按键映射自动保留，缺失的输出增益默认为 ×1。旧程序发出的整数包络参数仍被新固件接受。

验证数据见工程内 `reports/precision_validation.json`，设计和协议见 `docs/precision_protocol.md`。功能仿真、打包和布局布线不能代替实板听音与音质测量。严格 RTL 格式门禁结果独立保留，当前尚未通过。

2026-10-11 验证结果：桌面端 44 项测试、12 组 RTL 仿真通过；32 声部配对引擎每帧最大 247 个核心周期，帧预算 512，输出增益另外增加一拍。两版固件的建立与保持时序均无违例，最小余量分别为 0.006 ns / 0.005 ns，余量很小，仍需实板验证。资源为逻辑 23623/59904、寄存器 13928/60780、BSRAM 105/118、DSP 33/118。未执行实板烧录、串口连接或听音。
