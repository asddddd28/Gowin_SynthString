# 真实采样钢琴试听版

这版实现真实起音＋平滑循环尾音，32声部，与已有FM/AM共存。使用片内RAM；尚未接入DDR3，也不是88键多采样库。

## 快速试听

1. 关闭旧App。烧录 `output/demo1_pcm_31004.fs` 或 `output/demo1_pcm_31002.fs`，版本沿用之前串口正常连接的那一版。
2. 打开 `desktop/release_pcm/TangSynth32/TangSynth32.exe`。选择DEBUG UART串口并连接，等32键参数自动确认。
3. 点击“导入钢琴采样”，选App旁 `samples/Piano_C4_PCM.json`。上传约十几秒，提示数字会增长；成功后选中键自动切换为采样钢琴，并上传该键参数。
4. 想让32键全部弹钢琴，导入App旁的 `PCM_Piano_32Keys.json`。这会替换当前映射和音色，可先导出个人配置。默认键盘映射保留为1..8、Q..I、A..K、Z..逗号。
5. 默认范围C3–G5，建议先试中间的 `T`（C4），再试 `T+A+F`（C4/E4/G4）。总音量先25%；只调音量用“仅设置总音量”。

另外提供C3、A4采样包，可替换共享槽比较相应音区。右键选音键→“音色参数…”→载入“采样钢琴”预设→保存并上传，也能逐键与FM/AM混用。

## 实现和限制

- 采样源是用户提供的 `Piano 88Key Wav`，按此前确认的文件映射选取 tone(28)=C3、tone(40)=C4、tone(49)=A4。采样包内保留源文件SHA256与处理记录。
- 从原44.1k立体声选择较强声道；低通后转换成24k单声道16位。保留前180ms起音，后段适度补偿原始振幅衰减，以输出ADSR控制持续衰减。约32ms相关性匹配交叉淡化尾部接缝；总长不超过16384点（0.683秒）。
- FPGA仍以约96001.06Hz输出，播放24k素材时做线性插值。32个声部独立起音、变调和释放；只有一个共享样本和一套循环边界，不能32键各装不同录音。
- 数据RAM复制给两声部组，含整个工程共105/118块BSRAM。后续多音区/多力度长采样应转DDR3，目前未实现。
- PCM模式只使用A音量、音量ADSR、按键音高和力度；FM深度/B波形等不起作用。预设A=0保留原始起音，D=2500ms、S=0、R=180ms。包络整数步进使实际D约2.73秒，R按峰值计算斜率。
- 远离原始音高变调会改变琴体感、起音长度和带宽；高音可有混叠。每键只有一个力度来源，无踏板、共鸣或释放录音。这些是下一阶段的改进点。
- 单缓冲上传开始接收时旧采样失效；失败、中断或断电后需重传，不能回滚到旧采样。上传期间App阻止演奏。不要同时按住板载按键，否则等待空闲可能超时。
- 采样仅在RAM；GUI配置不嵌入采样。断电/复位后重新导入采样包。App配置独立保存于 `%LOCALAPPDATA%/TangSynth32/settings-pcm.json`，首次可迁移旧版逐键配置，不覆盖旧文件。

## 参考与验证

`output/PCM_Piano_C4_preview.wav` 为电脑模型合成并调整试听电平的参考：C4单音→C大三和弦，不是实板录音。

`reports/pcm_validation.json` 记录38项GUI/协议测试、PCM数值仿真、回归与两版布局布线结果。严格RTL样式门禁单独记录，未宣称通过；未自动烧录或作实板听感确认。
