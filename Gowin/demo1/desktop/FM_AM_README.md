# Tang Synth 32 · 逐键 FM / AM

## 使用

1. 关闭旧版 TangSynth32，使用 Programmer 烧录 `output/demo1_fmam_31004.fs` 或 `demo1_fmam_31002.fs`。沿用之前串口能正常连接的底板版本。仍为原来的耳机输出和 DEBUG USB UART 引脚。
2. 打开 `desktop/release_fmam/TangSynth32/TangSynth32.exe`，选择 DEBUG 串口并连接。App 自动上传 32 键参数；收到 FPGA 校验确认后，音键显示 ✓，才允许演奏。旧固件无法确认逐键参数，会提示超时。
3. 右键选择音键，点“音色参数…”。选择预设并点“载入预设到编辑框”，再“保存并上传此键”。“仅保存”只改电脑配置，之后要点“上传此键参数”。
4. 想快速试听：导入同目录的 `FM_AM_32Key_Demo.json`。键 1–8 是 FM 电钢琴，9–16 FM 钟声，17–24 FM 贝斯，25–28 AM 颤音，29–32 环形金属。保留默认键盘映射，导入会替换当前配置，先导出即可留存自己的设置。

键盘演奏仅在 App 获得焦点时生效；编辑输入框不触发音符。Esc 紧急停止。总音量可用“仅设置总音量”修改；“覆盖全部音键并上传”会把底部模板应用到全部 32 键。

## 模式与参数

- 波表混合：A、B 两个振荡器分别设波形、增益；B 可跟随 A 的频率比，或指定固定 Hz。
- FM / PM：两算子相位调制，B 改变 A 的读表相位。深度单位是**周期**，0.25 周期相当于峰值 π/2 弧度。B 音量只用于混合模式，对 FM 深度不起作用。
- AM：深度 0 为原音，1 为全幅单极调制；B 固定 5 Hz 的预设会故意产生颤音。
- 环形调制：深度 1 是 A×B 的双极乘法；深度 0 为原音，中间值混合原音与乘积。

音量 ADSR 控制响度；调制 ADSR 控制 FM/AM/环形深度。力度既控制输出响度，也可通过“力度→深度”改变音色。R 按峰值计算斜率，实际释放时间随松键瞬间的电平缩短。毫秒参数被转换为每采样整数步进，长包络时间会有量化误差。

B:A 比例范围 1/256..8，步长 1/256；固定 B 频率 0 表示使用比例，否则以 1/16 Hz 量化，最大 1000 Hz。比率模式 B DDS 增量上限对应约 24 kHz。FM 深度 0..2 周期、AM/环形 0..1。

## 保存与限制

- 32 声部，每声部 2 个振荡器，实际采样率约 96001.06 Hz；PT8211 输出 16 位。不是 32 套音频采样引擎。
- 每键的参数放在 FPGA RAM，起音时复制到声部；上传后的新参数用于下次起音，不会在按住的音中突然换音色。上传期间 App 暂停新音符并释放已按下音符。
- 单键上传是完整校验后一次提交；批量 32 键逐键提交，不是整批回滚。中途失败可能已有部分键提交，重新“上传全部参数”即可同步。
- RAM 断电丢失。App 配置保存于 `%LOCALAPPDATA%/TangSynth32/settings-perkey.json`，重新连接自动上传。首次启动可迁移旧版 settings.json，但不覆盖旧文件。
- 自定义波表仍是所有声部共享的一张 1024 点单周期表。A/B 都能选用；更换波表会影响所有使用该表的音键。上传完成会将开始上传时选中的键切换到自定义波表。电脑的配置 JSON 不包含波表内容，断电后需要重传波表。
- 当前 FM 是 PM 形式，没有反馈或 4/6 算子网络。高音、高频率比、大调制深度或方波/锯齿调制可产生混叠。先用正弦 A/B、适中深度试听。
- 邻近频率叠加仍会产生拍音；AM 低频调制也会主动产生响度起伏。这些不会被本次功能消除。
- 板载耳放底噪、实板音质尚待试听；未增加用户不需要的静音逻辑。

仿真、GUI 测试和两版 Gowin 时序结果见 `reports/fmam_validation.json`。技能的严格样式门禁仍未通过，不作为功能验证通过的依据。
