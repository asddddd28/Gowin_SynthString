# 合成钢琴版（2026-10-01）

关闭旧 App，运行 TangSynth32.exe，连接原 DEBUG COM 口后点击“钢琴预设”。沿用已有 FPGA 位流，不需要重新烧录。声音从板载耳机口输出。32 个键位、音高、力度和当前已应用总音量保留。

## 音色

这是用现有双振荡器构建的柔和电钢琴近似音色，不是原声钢琴采样。A 振荡器三角波 80%，B 振荡器正弦波 20%，失谐为零。起音约 2 ms；界面 D=1400 ms，受 FPGA 整数步长限制，实际满幅衰减约 1365 ms；持续电平为零，按住会自然渐弱。释放以峰值为参考，R=120 ms 对应满幅约 119 ms，衰减途中松键通常更短。力度仍控制响度，没有力度采样层或随时间变化的谐波。

点击“钢琴预设”会填入包络、应用并保存，保留音量。只在波形下拉框选择“钢琴（合成）”则只选择双振荡器配方，当前包络保持；使用预设按钮可一次设置完整音色。可继续编辑 ADSR 后点击“应用音色”。返回正弦/三角等波形后，根据需要恢复包络（例如 A=10、D=25.3、S=75、R=75.9）并应用。

共享 settings.json 新增了音色名称；旧版 App 不认识新音色，可能回退到默认配置。需要使用旧版时，先在新版中切回普通波形并应用保存。预设不会消除相邻半音叠加本身产生的拍音。

## 验证

17 项 GUI/协议/串口测试通过；FPGA EnvelopeStep 使用 App 实际生成的参数进行 xsim 仿真，通过快速起音、自然衰减、零电平保持及提前松键渐弱测试。没有修改生产 RTL、CST 或位流；未进行板上试听。测试日志见 reports/piano_gui_tests.log 和 piano_envelope_summary.log。
