# Tang Synth Studio 统一工作台

当前说明见 [UNIFIED_STUDIO.md](UNIFIED_STUDIO.md)。

默认进入“状态显示”：32 键、真实硬件 PCM 波形/频谱、数字输出延迟与链路诊断。点击音键进入声音设计，通过“选择预设音色”载入基础音色或 FM1 Convert。实体键与 App 共用逐键配置；支持 4 种同时使用的音色、8 复音。

已删除旧版工程切换与驻留音色栏，六算子编辑使用弹窗。普通重连沿用会话；仅板卡复位/烧录后建立新会话。

运行 TangSynthStudio.exe，并保留 assets、licenses 及许可证文件。当前固件为 50 MHz 干声版，2026-11-03 已完成 SRAM 烧录。频谱与波形为串口读取的硬件快照，不是连续录音。
