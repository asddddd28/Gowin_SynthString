# 触摸板演奏

长按摇杆 **0.8 秒**切换模式，保持按住不重复，松开后重新解锁。短按松手仍确认 HDMI 操作；长按不会误提交音色草稿。HDMI 页眉显示 `TOUCH 1..4`，App 状态页显示模式名称、位置及调制量。

| 模式 | 操作 | 灵敏度范围 |
| --- | --- | --- |
| 1 强度 | 左下减弱、右上增强，相对主音量调整 | ±0～100%，默认 ±25% |
| 2 音高 | 左下降调、右上升调 | ±0～12 半音，默认约 ±2 |
| 3 滤波 | 左下降低 Cutoff、右上提高，叠加原 LFO | ±0～6 oct，默认 ±2 |
| 4 吉他 | 上下划过四根横弦起音 | 每行最右侧按键优先 |

设备与输出 → **触摸板 · 演奏模式与灵敏度**，修改后点“应用触摸设置”。可交换 X/Y、反转左右或上下。仅编辑灵敏度时保留期间发生的摇杆切模式。配置在硬件确认后保存；普通重连读取硬件当前模式。

两块触摸板都能使用，连续调制同时有触点时优先左板，拨弦历史独立。松手平滑恢复，不覆盖音色与原滤波配置。固定频率算子不跟随音高调整。强度经过主音量上限保护，主音量已满时不能继续增益。

四弦从上到下对应 K01–K08、K09–K16、K17–K24、K25–K32。先按键选音，再划弦；空行静音，同一行多键取最右侧。落指、静止、断触后重新落下不发声。重复拨弦先释放旧音，确认后再起音。声音使用原音色包络：持续型音色会持续到松键或再次拨弦，建议使用短衰减音色。离开吉他模式后，已按住的键需松开再按。App/MIDI 仍可直接试听。

## 实现与证据

- 复用 demo_test 双 MPR121 采集与 I2C 核及引脚；有错误恢复、40 ms 过期保护与单簇检测。
- FPGA 内 1 kHz 控制更新、1/8 一阶平滑，不依赖串口往返。音高 LUT 约 0.094 半音/级。
- 最终时序无违例：系统约束 50 MHz / Fmax 50.177 MHz，像素约束 73.333 MHz / Fmax 75.995 MHz。最差 setup 裕量约 0.071 ns。
- CLS 26523/29952、BSRAM 113/118、DSP 68.5/118；相对原低通版增加 1233 CLS、3 BSRAM、4.5 DSP，RAM 剩 5 块。
- 位置/四模式/长短按与完整 UART→键源→Voice→PT8211 仿真通过。音高/增益 5120 帧、触摸 Cutoff/LFO 4096 帧与独立基准逐样本一致。原低通 12288 帧、HDMI 和整机回归通过。
- Rust 74 通过、1 忽略；触摸/低通、统一工作台/音色库 4 项 UI 测试通过。UI 使用模拟板卡。
- 已 SRAM 烧录。双 MPR 回读、四模式配置/回读、松手中性值、1/8 复音 PCM 和键盘扫描实板检查通过，零重试/坏包/欠载/超期。已恢复原四音色、32 键映射、校准、滤波、双簧管波表和主音量。
- 实际触摸方向、拨弦手感与听感仍需用户试奏确认。
- readable-verilog 严格风格门禁已运行：紧凑 ANSI 端口格式器规范化失败及风格问题，`delivery_ready=false`。未将其称为通过；编译、仿真、Gowin 和实板证据独立保存。
