# 上层事件音序器约定

- 时钟 50 MHz，复用 demo_test 六个高有效、5 ms 消抖按键；SW1=AA19、SW2=AB18、SW3=Y18、SW4=N15、SW5=U17、SW6=P15。
- 新操作映射（能力版本2）：SW1 录制/结束，SW2 清空当前工作区，SW3 手动保存，SW4 播放/暂停，SW5/SW6 上一条/下一条已存音序；BPM 在 App 设置。板上旧版能力1仍是SW3/4调BPM、SW5播放，App按能力显示，不混用。
- 首次录制按SW1立即开始节拍；4/4，首拍高音、后面三拍低音。等待首个Note-On后确定实际录音起点，去掉首音之前的空小节。首次录制窗口前移约20ms（960PPQ下floor(BPM*8/25)tick），稍早的首音归入下一小节，边界当拍属于新窗口。首次录音停止时仅保留已完成且有演奏的首尾小节，删除末尾纯空小节，保留中间休止与持续按键长音。未完成一个窗口不生成循环；已有叠录长度不改。录制结束关闭节拍音。
- 第一段确定循环长度；之后同长度叠录。记录接受的实体键盘/拨弦 Note-On/Off，不记录自身回放，避免反馈式增长。
- 时间以 960 PPQ 表示，BPM 20..300，默认120；一微秒基准分数累加，不用组合除法器。改变 BPM 保持音乐位置，只改变时间推进速率。
- 事件保存时间、音高增量、力度、音符、音色槽、开关与配对标识。播放独立 NoteID 命名空间，不冒用实时键盘的 NoteID。循环边界、暂停、清空释放回放声部，不发送全局 panic。
- 小节边界保存写指针、录音按键状态与配对索引，停止后丢弃本小节，给截断的长音补 Note-Off。保留至少32个事件用于截断收尾。
- 1024个90位事件，拆成5个18位存储区，避免宽 SDP 自动拆分浪费。溢出结束本次录制，只保留已经完成的小节，并上报满标志。
- 用户已确认：同长度叠录、每层保留录制时的音色、保存到 SD 卡并支持断电恢复。当前已实现片上 RAM 工作区和音色槽保护；SD 持久化尚未实现，不能将 RAM 录音称为完成整个需求。
- 已提交和正在录制使用的音色槽将作为保留槽上报。4个音色槽/8个声部仍是当前系统限制。
- 事件回放通过独立请求源加入原 AXI 命令仲裁；接受后等待对应响应，保持请求稳定，且不阻塞音频固定采样输出。
- 本轮保持 HDMI、键盘、触摸、音频采样配置。新增节拍声是独立、限幅的小音量监控声。
- 保存必须由结束录制后的 SW3 明确触发，不在停止录制时自动写卡；播放过程中保存时，快照阶段可短暂暂停回放，完成后恢复原播放状态。录音中拒绝保存，不截掉当前层。
- `SEQUENCES/00000001.SSQ` 起递增编号；每次保存创建新编号，已有文件不覆盖。保存内容包含事件、BPM、四个音色页和共享波表。中断的新文件不参与回放，也不复用其编号。
- HDMI 增加音序库、SD音色库两页；初次加载目录选择最新有效序号；前后切换跳过损坏/已删除条目，到首尾停住。切换前有未保存录音时要求保存或明确丢弃，不可静默清空。
- 音序管理支持查看、载入/回放和二次确认删除。SW2仅清当前RAM录音，不删除SD文件。删除不重排或复用旧序号。
- `PRESETS/00000001.SSP` 为 App 预传输的自包含预设（单音色页+波表+名称+CRC）。HDMI选中后加载当前Slot；已被录音层保留的Slot拒绝覆盖。共享波表不同且其他录音层使用波表时拒绝替换，提示先清空或使用兼容预设。
- 两个新页面共用已有11块字符ROM和1024字节文本RAM；不增加帧缓冲，不更改波形采样、频谱DFT或PCM节奏。SD未就绪时明确显示未挂载，绝不显示虚构文件或保存成功。

验证覆盖：小节边界两侧停止、不足一小节、静音小节、多小节、BPM改变、消抖长按、循环与跨边界长音、叠录、同键实时与回放并存、满缓冲、清空时背压、重复录制开关、串口无效参数；完整顶层 UART/AXI/PCM 和 Gowin 50 MHz 布局布线。
