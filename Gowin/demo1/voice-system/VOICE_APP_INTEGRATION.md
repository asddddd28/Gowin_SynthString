# Voice App：FM / AM / 波表与六算子弹窗

2026-11-03。仅修改 App、原生 Rust 编译和串口控制代码；板上仍使用已验证的 50 MHz 干声固件，未更改 RTL 或重新烧录。

## 使用

运行 `app/TangSynthStudio.exe`，进入 **声音设计 → Voice 硬件**，连接板卡实际 FTDI 调试串口（本次为 COM4）。普通重连不要勾选“建立新会话”。

1. 选择四个驻留槽之一。App / MIDI 新音符使用所选槽；实体键盘当前使用槽 1。
2. 在“音色配置”选择 **FM / PM、线性 FM、AM、环形调制、波表合成**，调整波形、频率比/固定频率、电平、调制深度和线性包络，点击“提交音色至 FPGA”。提交会停止旧声部，再按键试听。
3. **六算子配置**按钮打开可滚动模态窗口。Native 模式允许六行启用、载波输出、前序算子路由、独立波形/模式/包络和历史反馈；关闭窗口保留当前槽草稿，主界面提交后生效。
4. FM1 Convert 音色继续使用 DX 包络与原算法：在同一个弹窗修改输出电平、比率/固定频率、DX 四段速率和电平，再点击弹窗内的提交按钮。FM1 算法仍沿用导入音色，不会转换为 Native 线性包络。
5. 原有工作台保留在“旧版工程”选项中。旧配置文件、32 键波表/PCM/SD 协议没有被隐式转换成当前四槽 Voice 程序。当前新功能使用 Voice 硬件配置。

FM1 Convert 仍收录 128 条元数据，8 条可装载；本次没有把剩余条目宣称为已适配。

## 波表工坊

保留原有素材导入、选帧、位置和波形预览。新增 **Voice 共享波表 → 上传当前相邻双帧**，从资源解析器取得完整的 2 × 1024 点 signed16 样本（不能上传降采样的预览），转换为 Q26 后发送 A8 指令。

- 表是整个引擎共享的资源，任何使用波表的槽都会受换表影响。
- 开始时发送 A7 停音并清空声部；每批确认 16 点，显示进度。
- 上传元数据、全部源样本、已确认位置与单条 pending 请求保存在当前端口的会话文件中。
- 暂停、切页、退出或掉线时保留进度并保持停音；重连后恢复原 pending，再点击继续。
- 全部 2048 点确认后才发送 A7 恢复演奏，不能播放部分更新的波表。
- 上传完成后点击 **使用已上传波表 · 槽 N**，创建 Native 波表音色并带入上传时的帧间位置。后续可在声音设计中调整 0–1 的双帧位置。
- 当前仍是 115200 波特率、逐条确认，上传通常需数十秒。本次没有改变 FPGA 协议以批量突发上传，也没有加入 SD 音色缓存。

## 数值和路由约束

Native 六行按 OP1 → OP6 执行；输入源只能引用前序行，输出载波可多选，历史反馈独立配置。Native 比率 0–16，PM/FM 深度和反馈采用有符号整圈相位字（范围 -0.5 到小于 0.5 周期），AM/Ring 深度为 0–1。Native 包络时间表示满量程线性斜坡时间；DX 音色保留已有对数 EG 速率语义。两者释放目标均须为零。

Rust 在发送前校验名称、槽位、六行完整性、非有限数、参数范围、载波存在性及无环源索引；不合法数据不会先停音再报错。更新 DX/Native 类型时先停止活动声部，避免不兼容的包络状态跨类型继承。音色由 A0/A1/A2/A3 编译并原子提交。

## 验证结果

- 50 项 Rust 测试通过：新增 Native AM 编码、波表 Morph、负 FM 深度、非法图/数值以及完整波表与预览分辨率分离。
- 原有 11 项工作台界面回归通过。新合并流程复测通过：删除独立 FM 导航、打开/关闭 DX 弹窗、AM 深度提交、Native 六行路由、2048 点上传、波表建音色、切页松键及 1080 / 1440 布局。FM 界面测试采用明确测试适配器，不冒充实板结果。
- 实板 `voice-probe --native-audition` 使用 App 同一份 Rust Engine：PM、FM、AM、Ring 三音和弦均返回 active=7；两帧波表的 Morph=0、0.5、1 均返回八复音 active=255。测试 Native 音色只有一至两个启用算子，测得 200 / 349 周期，不作为满六算子最坏时序。
- 上传到 32 点后主动断开、重连，进度仍为 32，继续完成 2048 点；上传期间 Note On 在本地被拒绝且没有发包。
- 整个测试各连接的重试为零；硬件通信坏包、音频欠载、PCM 丢帧和 Voice 超时均为零。恢复测试前四槽参数与主音量；共享波表保留已测试的正弦/三角双帧。
- 应用户要求再次播放五种音色，每种约两秒，随后恢复原槽。用户在第二轮试听后确认：“听到了，声音正常”。未进行模拟输出波形录音或端到端延迟测量。
- 最终原生 App 已连接 COM4，检查声音设计入口及六算子弹窗打开/关闭正常。
