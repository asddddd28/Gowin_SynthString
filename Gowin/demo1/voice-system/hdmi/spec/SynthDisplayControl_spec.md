## 5. 周期行为与延迟

- Protocol5 kind3 opcodes0x10..0x13 implement capability, page, eight-byte metadata write and absolute input counters.
- Five encoder inputs pass two synchronizers and50us filtering; illegal Gray transitions do not count. Joystick requires5ms stable.
- Electrical bit0=H/bit1=L:00 low,01 centre,11 high,10 invalid. Startup settling and centre-to-arm prevent held inputs, releases or invalid transitions from generating actions.
- X high advances page, low reverses; Y high decrements focus, low increments. Horizontal has priority for diagonal moves. Switch low emits one confirmation after release-to-arm.
- Page bounds checked; text writes acknowledge after all eight write edges. UART exact replay belongs to existing SynthUartControl. Host-live expires2seconds after last input query.
- 摇杆按下800ms产生单次o_touch_next，保持不重复；松手重新解锁。短按确认改为松手发出，长按松手不会确认音色草稿。
- HDMI能力版本0x10001，支持0..7共八页；0x11参数8及以上拒绝，左右自然三位回绕。0..5兼容原页面，6为音序库，7为SD音色库。
- 显示接口仍为0x10..0x13和1024字节文本RAM；不直接执行文件写入。库页面上的旋钮/确认语义由存储控制器接管，不可误应用算子草稿。

## 7. 边界、反压与错误

- Reset while transfer pending; invalid opcode/argument; sustained key; missing display consumer.
- No host connection: monitoring and page navigation continue; metadata edits require connected App.

## 8. CDC 与综合约束

- 50MHz system; 73.333333MHz pixel; related5x serializer. Hold multi-bit CDC payload through toggle acknowledgement.
- ROM/RAM contents generated by prepare_assets.mjs; no asynchronous array reset.
