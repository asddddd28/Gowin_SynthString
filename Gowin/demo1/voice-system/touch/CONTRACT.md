# Touch performance contract

50 MHz hardware control; existing dual MPR121 open-drain scanner is reused unchanged. A single contiguous electrode cluster on both axes is required. Positions use weighted deltas, normalized to 0..1023. Raw row-axis is display X, column-axis is display Y, matching the demo's default transposed display. App exposes swap/flip correction. Missing, failed or older-than-40ms data means no touch; two pads have independent stroke history, pad 1 has priority for continuous modulation when both are touched.

Modes 0..3 correspond to user modes 1..4: volume, pitch, cutoff, guitar. Long joystick press 800ms advances once; release re-arms; short release confirms the existing HDMI UI, a long press must never confirm it.

Continuous diagonal position is X-Y: bottom-left negative, top-right positive, centre neutral. Volume range 0..100%, pitch range 0..12 semitones, cutoff range 0..6 octaves. Targets update at 1kHz; first-order smoothing returns to unity/zero on release. Modulation is transient and does not rewrite the patch, user master gain or filter profile. Voice pitch offsets add to existing pitch modulation and saturate within the engine's supported range; fixed-frequency operators retain their fixed tuning. Cutoff temporarily activates the global lowpass while touching, adds to its log cutoff and coexists with its LFO.

Guitar: four horizontal strings at Y=128,384,640,896, hysteresis20, 12ms per-string cooldown, continuity40ms. Only continuous crossings pluck. Touch-down, hover, dropout, invalid multi-touch, stale data and mode/orientation change clear/reseed the stroke. Rows map K01..08,K09..16,K17..24,K25..32; the rightmost held key in a row wins, empty rows are silent. Each row has one pending target; repeated pending requests coalesce with an explicit counter. Release old row notes and wait for keyboard delivery to settle before retriggering, preserving note identity. Entering/leaving guitar mutes physical-key voices; leaving guitar suppresses held keys until release. Changes among continuous modes preserve held keys. Guitar notes follow the configured envelope and stop when their selected physical key is released or the next pluck replaces them; no additional forced decay is imposed. App/MIDI audition remains direct.

UART kind3 opcodes: 0x30 capability TOU1/version1; 0x31 atomic settings (word0 mode[1:0],swap[2],flipX[3],flipY[4]; word1 gain[7:0]0..128,pitch[15:8]0..128,cutoff[23:16]0..192); 0x32 status; 0x33 configuration/live values. No pad packets traverse the serial port to drive audio. Existing UART sequence/replay protects writes. AXI still owns patches and baseline DSP settings; registered hardware modulation sidebands only supply transient performance sources.

Validation: weighted position fixtures, dropouts, four simultaneous crossings, rightmost selection, repeated pluck with an in-flight Note-On/Off, empty rows, mode transition, long/short joystick actions, signed modulation limits and neutral return. Full existing audio, lowpass and HDMI regressions; 50MHz Gowin resource/timing evidence before programming. Existing firmware/App/session are backed up; hardware settings are restored after SRAM programming using the fresh-session workflow.

Response payload words are little-endian at standard UART response byte8,12,16,20; response status is the existing common status field. `0x32`: word0 mode[1:0], live-pad bitmap[3:2], any-contact[4], selected-pad[5], left-error[15:8], right-error[23:16]; word1 X[9:0],Y[19:10]; word2 strums[15:0],coalesced[31:16]; word3 signed live pitch delta Q26. `0x33`: word0 settings flags, word1 ranges, word2 unsigned live gain Q16, word3 signed live cutoff index offset. `0x31` echoes two accepted settings words; malformed/reserved/range/argument data returns5 without changing configuration. Replay is owned by SynthUartControl, so exact repeats are never interpreted as another mode-advance event.

Hardware notes: continuous targets update every1ms, settle using a1/8 first-order smoother (about8ms time constant). MPR acquisition latency and smoothing are distinct from the existing digital NoteOn-to-DAC monitor. Pitch LUT spans[-12,+11.90625]semitones with0.09375semitone spacing; diagonal scaling may stop one table step short at the positive corner. These limits are explicitly not claims of continuous floating-point pitch or submillisecond end-to-end touch response.
